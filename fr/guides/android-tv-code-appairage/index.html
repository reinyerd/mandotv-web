Android TV demande un code d'appairage : que faire

La première fois que vous connectez votre téléphone à une Android TV ou Google TV, la TV affiche un code de 6 caractères à l'écran. C'est normal et cela n'arrive qu'une fois : cela garantit que personne d'autre ne peut piloter votre TV. Voici comment le saisir et que faire s'il n'apparaît pas.

Voir les étapes Télécharger gratuitement

Pas à pas

  1. Allumez la TV et laissez l'écran d'accueil visible.
  2. Ouvrez Mando TV sur votre téléphone, sur le même Wi-Fi que la TV, et touchez votre TV dans la liste.
  3. Regardez l'écran de la TV : un code de 6 lettres et chiffres apparaît.
  4. Saisissez-le sur votre téléphone exactement comme il s'affiche et touchez Associer. Les lettres vont seulement de A à F : un caractère rond est donc toujours le chiffre zéro.
  5. Et voilà. La TV mémorise votre téléphone et ne redemande pas le code.

Si le code n'apparaît pas sur la TV

Vérifiez que la TV est vraiment allumée et pas en veille, et que votre téléphone est sur le même Wi-Fi. Touchez de nouveau la TV sur votre téléphone. S'il n'apparaît toujours pas, redémarrez la TV : débranchez-la dix secondes, rebranchez-la et réessayez.

S'il indique que le code est faux

Le code change à chaque demande. Si vous avez mis du temps ou l'avez demandé deux fois, seul le dernier affiché à l'écran fonctionne. Touchez de nouveau la TV sur votre téléphone et saisissez le nouveau code.

Si la TV redemande le code

Cela arrive quand la TV est réinitialisée aux paramètres d'usine ou quand vous effacez les données de l'application sur votre téléphone. Associez de nouveau et c'est enregistré. Si vous n'avez aucune télécommande, lisez Android TV sans télécommande.

Questions fréquentes

Quelles TV utilisent ce code ?

Celles sous Android TV ou Google TV : Sony, Philips, TCL, Hisense, Sharp, Xiaomi, Chromecast avec Google TV et plusieurs autres.

Ai-je besoin d'un compte Google sur mon téléphone ?

Non. Le code affiché à l'écran suffit.

Est-ce sûr ?

Oui. Le code prouve que vous êtes devant la TV : personne ne peut associer un appareil sans le voir à l'écran.
