Windows 電腦的遙控器 App

Mando TV 有 Windows 版 App，透過家用網路把你的電腦或筆電變成電視遙控器。用你真正的鍵盤在電視上輸入文字，工作時讓一個小小的遙控器視窗留在最上層，並用同一個 App 控制 Samsung、LG、Roku、Google TV 或 Fire TV。

看看它如何運作

步驟說明

  1. 從 Microsoft Store 免費安裝 Mando TV 到 Windows 10 或 11 的電腦。
  2. 確認電腦與電視在同一個網路，透過 Wi-Fi 或網路線接在同一台路由器。
  3. 開啟 Mando TV。電視會出現在清單中，按一下它即可。
  4. 如果電視有詢問（LG、Samsung），請確認提示；或輸入顯示的代碼（Google TV、Fire TV）。
  5. 按一下按鍵，或用鍵盤輸入搜尋內容。完成。

快捷鍵（Pro）

使用 Pro，你的電腦鍵盤就是遙控器：方向鍵移動、Enter 為確定、Backspace 或 Esc 為返回、加號與減號調整音量、M 為靜音、空白鍵為暫停。

迷你遙控器（Pro）

一個小小的遙控器視窗，會停留在所有其他視窗上方。這樣你調整音量或暫停時，不必中斷手邊的工作。

從電腦在電視上輸入文字

電視的螢幕鍵盤很慢。在 Mando TV 中，你可以用真正的鍵盤輸入，文字會出現在電視的搜尋欄。這個部分是免費的。

從電腦下語音指令（Pro）

使用 Pro，你可以透過電腦的麥克風對電視說話。語音會直接在電腦上辨識：不需要網際網路，也不必在 Windows 中更改任何設定。你說的話絕不會離開電腦，也不會被儲存。只有非常舊的處理器，App 才會改用 Windows 的語音輸入。這時需要在隱私權設定中開啟線上語音辨識，並在 Windows 中新增你的語言。

常見問題

Windows 遙控器 App 需要藍牙或線材嗎？

不需要。它使用你的家用網路。電腦與電視只要接在同一台路由器即可。

我可以從 Windows 控制哪些電視？

採用 Tizen 的 Samsung 電視、採用 webOS 的 LG 電視、Roku 電視與播放器、Google TV 與 Android TV，以及 Fire TV。

我可以在電腦上看電視畫面，或從電腦喇叭聽到聲音嗎？

不行。Mando TV 只是遙控器。它不會把電視畫面鏡射或串流到電腦。

為什麼語音在我的 Windows 電腦上不能用？

語音控制是 Pro 功能。請確認 Pro 已啟用，且電腦的麥克風可以正常運作。在大多數電腦上，語音會直接在電腦上辨識，不需要網際網路。只有非常舊的處理器，App 才會使用 Windows 的語音輸入：這時請在 Windows 隱私權設定中開啟線上語音辨識，並在語言設定中新增你的語言。
