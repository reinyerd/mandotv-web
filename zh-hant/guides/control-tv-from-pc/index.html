如何用 Windows 電腦控制電視

如果你整天都在電腦前，就不必再到處找遙控器：Windows 版 Mando TV 可以透過家中的 Wi-Fi 控制你的 Samsung、LG、Roku、Google TV 或 Android TV 電視。切換 App、調整音量，或用電腦鍵盤在 YouTube 輸入文字都很方便。

查看步驟 免費下載

步驟說明

  1. 從 Microsoft Store 免費下載 Mando TV 到你的 Windows 10 或 11 電腦。
  2. 確認電腦與電視在同一個網路（Wi-Fi 或網路線皆可，但要接同一台路由器）。
  3. 開啟 Mando TV：你的電視會自動出現在清單中。點選或按一下它即可。
  4. 第一次請在電視畫面上確認連線（Google TV 與 Android TV 則要輸入電視顯示的代碼）。
  5. 完成：用按鍵或鍵盤，就能在電視的搜尋欄輸入文字。觸控板是 Pro 功能。

電腦快捷鍵（Pro）

使用 Mando TV Pro，你可以用電腦鍵盤控制電視：方向鍵導覽、Enter 為確定、Backspace 或 Esc 為返回、+ 與 - 調整音量、M 為靜音、空白鍵為暫停。

隨時置頂的迷你遙控器（Pro）

工作或在電腦上玩遊戲時，讓一個小小的遙控器視窗隨時顯示在最上層。

從電腦對電視說話（Pro）

使用 Mando TV Pro，你可以透過電腦的麥克風對電視下指令：「開啟 YouTube」、「大聲一點」或「30 分鐘後關機」，用平常說話的方式就行。在 Windows 上，語音會在電腦本機辨識：不需要網際網路，也不必更改 Windows 設定，並支援 App 的 6 種語言。你說的話不會離開電腦，也不會被儲存。只有非常舊的處理器，App 才會改用 Windows 的語音聽寫。這時需要在隱私權設定中開啟線上語音辨識，並在 Windows 中新增繁體中文（台灣）。如果缺少任何一項，App 會通知你，並用按鈕開啟設定。

常見問題

用電腦控制電視需要線材或藍牙嗎？

不需要。Mando TV 透過你的家用網路連線：電腦與電視只要接同一台路由器即可。

每一台電視都能用嗎？

支援採用 Tizen 的 Samsung 電視（2016 年及之後）、採用 webOS 的 LG、Roku，以及 Google TV 或 Android TV（Sony、Philips、TCL、Hisense、Sharp、小米、Toshiba、Panasonic、Haier、Skyworth 等）。

要多少錢？

按鍵、鍵盤與透過網路開機都是免費的，且沒有廣告。Mando TV Pro 是一次買斷、不需訂閱的方案，提供觸控板、電腦快捷鍵與迷你遙控器等額外功能。

為什麼麥克風在 Windows 上聽不懂我說的話？

請確認語音功能已啟用（屬於 Pro），且電腦的麥克風在 Windows 中可以正常運作。幾乎所有電腦都能在本機辨識語音，完全不需要網際網路。只有非常舊的處理器，App 才會改用 Windows 的語音聽寫。這時請確認 Windows 隱私權設定中已開啟線上語音辨識，且語言設定中有繁體中文（台灣）。Mando TV 只在聆聽期間使用這個語言。
