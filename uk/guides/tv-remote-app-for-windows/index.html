Застосунок-пульт для комп’ютера на Windows

У Mando TV є застосунок для Windows, який перетворює ваш комп’ютер чи ноутбук на пульт для телевізора через домашню мережу. Вводьте текст на телевізорі справжньою клавіатурою, тримайте під час роботи маленьке вікно пульта поверх решти й керуйте Samsung, LG, Roku, Google TV чи Fire TV одним застосунком.

Переглянути кроки Завантажити безкоштовно

Крок за кроком

  1. Встановіть Mando TV безкоштовно з Microsoft Store на комп’ютер із Windows 10 або 11.
  2. Переконайтеся, що комп’ютер і телевізор в одній мережі, через Wi-Fi або кабелем до одного роутера.
  3. Відкрийте Mando TV. Телевізор з’явиться в списку. Клацніть на ньому.
  4. Підтвердьте запит на телевізорі, якщо він питає (LG, Samsung), або введіть код, який з’явиться на екрані (Google TV, Fire TV).
  5. Клацайте кнопки або вводьте пошуковий запит із клавіатури. Готово.

Гарячі клавіші (Pro)

З Pro клавіатура комп’ютера стає пультом: стрілки для переміщення, Enter для OK, Backspace або Esc для «Назад», плюс і мінус для гучності, M для вимкнення звуку й пробіл для паузи.

Міні-пульт (Pro)

Маленьке вікно пульта, яке залишається поверх усіх інших вікон. Так можна змінити гучність чи поставити на паузу, не відриваючись від роботи.

Введення тексту на телевізорі з ПК

Екранна клавіатура телевізора повільна. У Mando TV ви друкуєте справжньою клавіатурою, а текст потрапляє в поле пошуку телевізора. Ця частина безкоштовна.

Докладніше

Покрокову інструкцію дивіться в Керування телевізором з комп’ютера. Для смартфона прочитайте Смартфон як пульт через Wi-Fi.

Безкоштовно й Pro

Стрілки, OK, Назад, Головна, гучність, канали, цифрові кнопки, клавіатура, відкриття застосунків, зміна входів і вмикання чи вимикання безкоштовні, без реклами й без підписки. Mando TV Pro — необовʼязкова одноразова покупка для додаткових можливостей. У Windows Pro купується через Microsoft Store.

Голосові команди з ПК (Pro)

З Pro можна розмовляти з телевізором через мікрофон комп’ютера. Мова розпізнається прямо на комп’ютері: інтернет не потрібен і нічого змінювати у Windows не треба. Те, що ви кажете, ніколи не залишає комп’ютера й не зберігається. Лише на дуже старих процесорах застосунок переходить на голосове введення Windows. Для цього в налаштуваннях конфіденційності має бути ввімкнене онлайн-розпізнавання мови, а вашу мову додано у Windows.

Поширені запитання

Чи потрібен застосунку-пульту для Windows Bluetooth або кабель?

Ні. Він використовує вашу домашню мережу. Комп’ютер і телевізор мають лише бути підключені до одного роутера.

Якими телевізорами можна керувати з Windows?

Телевізорами Samsung на Tizen, LG на webOS, Roku TV і програвачами, Google TV та Android TV, а також Fire TV.

Чи можна бачити зображення телевізора на ПК або чути звук через динаміки ПК?

Ні. Mando TV — лише пульт. Він не дзеркалить і не транслює зображення телевізора на комп’ютер.

Чому голос не працює на моєму комп’ютері з Windows?

Голосове керування — функція Pro. Тож перевірте, чи Pro активний і чи працює мікрофон комп’ютера. На більшості комп’ютерів мова розпізнається прямо на пристрої, без інтернету. Лише на дуже старих процесорах застосунок використовує голосове введення Windows: тоді ввімкніть онлайн-розпізнавання мови в налаштуваннях конфіденційності Windows і додайте свою мову в мовних налаштуваннях.
