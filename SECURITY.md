# Security

If you found a security problem in mandotv.app or in the Mando TV app, please tell us before making it public.

- Write to **hola@mandotv.app** (English or Spanish). A short description, the page or app version, and the steps to
  reproduce it are enough.
- We read every report, answer as soon as we can and fix confirmed problems before they are announced.
- Please do not access other people's data, do not test against TVs or networks that are not yours and do not run
  automated attacks against the site.
- This repository is public and only contains the website. Never commit keys or tokens: if you see one here, report it
  to the same address and we will rotate it.

The machine-readable version is at <https://mandotv.app/.well-known/security.txt>.
