如何用 Windows 电脑控制电视

如果你一整天都对着电脑，就不必再去找遥控器：Windows 版 Mando TV 通过你家的 WiFi 控制三星、LG、Roku、Google TV 或 Android TV 电视。切换应用、调音量，或者用电脑键盘在 YouTube 里打字，都很方便。

查看步骤 免费下载

分步操作

  1. 在装有 Windows 10 或 11 的电脑上，从 Microsoft Store 免费下载 Mando TV。
  2. 确认电脑和电视在同一个网络里（WiFi 或网线都可以，但要接在同一个路由器上）。
  3. 打开 Mando TV：你的电视会自动出现在列表中，点击它。
  4. 第一次需要在电视屏幕上确认连接（对于 Google TV 和 Android TV，则输入电视显示的代码）。
  5. 完成：用按键，或用键盘在电视的搜索框里输入文字。触控板是 Pro 功能。

电脑快捷键（Pro）

有了 Mando TV Pro，你可以用电脑键盘控制电视：方向键导航，回车为确认，退格或 Esc 为返回，+ 和 - 调节音量，M 静音，空格键暂停。

始终置顶的迷你遥控器（Pro）

工作或在电脑上玩游戏时，让一个小遥控器窗口始终显示在最前面。

用电脑对电视说话（Pro）

有了 Mando TV Pro，你可以通过电脑的麦克风向电视发出指令：“打开 YouTube”、“声音大一点”或“30 分钟后关机”，用你平时说话的方式就行。在 Windows 上，语音直接在电脑本机识别：不需要联网，也不用改动 Windows 设置，并支持应用的 6 种语言。你说的话不会离开电脑，也不会被保存。只有在处理器非常老旧时，应用才会改用 Windows 的听写功能。这时需要在隐私设置中打开在线语音识别，并在 Windows 中添加中文（简体，中国）。如果缺少什么，应用会提示你，并用一个按钮打开对应的设置。

常见问题

用电脑控制电视需要连线或蓝牙吗？

不需要。Mando TV 通过你的家庭网络连接：电脑和电视只要接在同一个路由器上就行。

所有电视都能用吗？

支持搭载 Tizen 的三星电视（2016 年及以后的型号）、搭载 webOS 的 LG、Roku，以及 Google TV 或 Android TV（索尼、飞利浦、TCL、海信、夏普、小米、东芝、松下、海尔、创维等）。

要花多少钱？

按键、键盘和通过网络开机都是免费的，没有广告。Mando TV Pro 是一次性买断，无需订阅，提供触控板、电脑快捷键和迷你遥控器等额外功能。

为什么 Windows 里的麦克风听不懂我说话？

请确认语音功能已启用（它属于 Pro），并且电脑的麦克风在 Windows 中可以正常使用。几乎所有电脑都是在本机识别语音，完全不需要联网。只有处理器非常老旧时，应用才会使用 Windows 的听写功能。这时请检查 Windows 隐私设置中的在线语音识别是否已打开，并且 Windows 的语言设置里有中文（简体，中国）。Mando TV 只在聆听期间使用这种语言。
