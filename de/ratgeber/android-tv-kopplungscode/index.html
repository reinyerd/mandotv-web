Android TV fragt nach einem Kopplungscode: Das ist zu tun

Wenn du dein Handy zum ersten Mal mit einem Android TV oder Google TV verbindest, zeigt der Fernseher einen Code mit 6 Zeichen auf dem Bildschirm. Das ist normal und passiert nur einmal: So ist sichergestellt, dass niemand sonst deinen Fernseher steuern kann. Hier siehst du, wie du ihn eingibst und was du tust, wenn er nicht erscheint.

Schritte ansehen Kostenlos herunterladen

Schritt für Schritt

  1. Schalte den Fernseher ein und lass den Startbildschirm sichtbar.
  2. Öffne Mando TV auf deinem Handy, im selben WLAN wie der Fernseher, und tippe in der Liste auf deinen Fernseher.
  3. Schau auf den Bildschirm des Fernsehers: Ein Code aus 6 Buchstaben und Zahlen erscheint.
  4. Tippe ihn genau so auf deinem Handy ein, wie er angezeigt wird, und tippe auf Koppeln. Die Buchstaben gehen nur von A bis F, ein rundes Zeichen ist also immer die Zahl Null.
  5. Fertig. Der Fernseher merkt sich dein Handy und fragt nicht noch einmal nach dem Code.

Wenn der Code nicht auf dem Fernseher erscheint

Prüfe, ob der Fernseher wirklich eingeschaltet ist und nicht im Standby, und ob dein Handy im selben WLAN ist. Tippe auf deinem Handy noch einmal auf den Fernseher. Erscheint er immer noch nicht, starte den Fernseher neu: Ziehe den Stecker zehn Sekunden lang, stecke ihn wieder ein und versuche es erneut.

Wenn der Code als falsch gemeldet wird

Der Code ändert sich bei jeder Anfrage. Hast du lange gebraucht oder ihn zweimal angefordert, funktioniert nur der letzte auf dem Bildschirm. Tippe auf deinem Handy noch einmal auf den Fernseher und gib den neuen Code ein.

Wenn der Fernseher erneut nach dem Code fragt

Das passiert, wenn der Fernseher auf Werkseinstellungen zurückgesetzt wurde oder du die App-Daten auf deinem Handy löschst. Koppele erneut, dann ist er gespeichert. Hast du gar keine Fernbedienung, lies Android TV ohne Fernbedienung.

Häufige Fragen

Welche Fernseher nutzen diesen Code?

Die mit Android TV oder Google TV: Sony, Philips, TCL, Hisense, Sharp, Xiaomi, Chromecast mit Google TV und einige mehr.

Brauche ich ein Google-Konto auf meinem Handy?

Nein. Der Code auf dem Bildschirm ist alles, was du brauchst.

Ist das sicher?

Ja. Der Code beweist, dass du vor dem Fernseher sitzt: Niemand kann koppeln, ohne ihn auf dem Bildschirm zu sehen.
