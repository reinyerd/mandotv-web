Windowsパソコン用のリモコンアプリ

Mando TVには、パソコンやノートパソコンをご家庭のネットワークを通してテレビのリモコンに変える、Windowsアプリがあります。本物のキーボードでテレビに文字を入力でき、作業中は小さなリモコンのウィンドウを手前に表示しておけます。Samsung、LG、Roku、Google TV、Fire TVを、同じアプリで操作できます。

実際の動きを見る

手順

  1. Windows 10か11のパソコンに、Microsoft StoreからMando TVを無料でインストールします。
  2. パソコンとテレビが、同じネットワーク(Wi-Fiでも有線でも、同じルーター)にあることを確認します。
  3. Mando TVを開きます。テレビが一覧に表示されます。クリックしてください。
  4. テレビが確認してきた場合(LG、Samsung)は承認し、コードが表示された場合(Google TV、Fire TV)は入力します。
  5. ボタンをクリックするか、キーボードで検索ワードを入力します。これで完了です。

ショートカットキー(Pro)

Proなら、パソコンのキーボードがリモコンになります。矢印キーで移動、Enterで決定、BackspaceまたはEscで戻る、プラスとマイナスで音量、Mで消音、スペースキーで一時停止です。

ミニリモコン(Pro)

ほかのウィンドウの上に表示され続ける、小さなリモコンのウィンドウです。作業を中断せずに、音量の調整や一時停止ができます。

パソコンからテレビに文字を入力

テレビの画面上のキーボードは、入力に時間がかかります。Mando TVなら、本物のキーボードで入力した文字が、テレビの検索欄に入ります。この機能は無料です。

くわしい情報

手順は、パソコンでテレビを操作するでくわしく紹介しています。スマホについては、Wi-Fiでスマホをリモコンとして使う方法をご覧ください。

無料とPro

矢印キー、決定、戻る、ホーム、音量、チャンネル、数字キー、キーボード、アプリを開くこと、入力の切り替え、電源のオンとオフは、無料で、広告もサブスクリプションもありません。タッチパッド、音声コマンド、お気に入りのアプリ、ルーティン、スリープタイマーは、サブスクリプションなしの買い切りであるMando TV Proに含まれます。Windowsでは、ProをMicrosoft Storeで購入します。

パソコンからの音声コマンド(Pro)

Proなら、パソコンのマイクを通して、テレビに話しかけられます。音声はパソコン本体で直接認識されるため、インターネットは不要で、Windowsで何かを設定する必要もありません。話した内容はパソコンの外には出ず、保存もされません。非常に古いプロセッサーの場合のみ、アプリはWindowsの音声入力に切り替わります。その場合は、プライバシー設定でオンライン音声認識をオンにし、Windowsにお使いの言語を追加しておく必要があります。

Mando TVでの操作方法

Mando TVは、テレビ用のユニバーサルリモコンアプリです。無料でダウンロードでき、広告もアカウント登録もありません。Proは任意の買い切りで、サブスクリプションはありません。iPhone、iPad、Windows、Android向けです:

  • ダウンロード:App Store
  • ダウンロード:Microsoft Store
  • 先行アクセス:Google Play

Android版はGoogle Playで無料の先行アクセス中です。2ステップで参加して、ストア公開にご協力ください。

Microsoft Storeのページ： apps.microsoft.com/detail/9N3D7T1DP2SW

よくある質問

Windows用のリモコンアプリに、Bluetoothやケーブルは必要ですか?

いいえ。ご家庭のネットワークを使います。パソコンとテレビが、同じルーターにつながっていれば大丈夫です。

Windowsからは、どのテレビを操作できますか?

Tizen搭載のSamsungテレビ、webOS搭載のLGテレビ、Roku TVとRokuプレーヤー、Google TVとAndroid TV、そしてFire TVです。

テレビの映像をパソコンで見たり、パソコンのスピーカーで聞いたりできますか?

いいえ。Mando TVはリモコンだけです。テレビの映像を、パソコンにミラーリングしたり、ストリーミングしたりはしません。

Windowsのパソコンで音声が動かないのはなぜですか?

音声操作はProの機能です。Proが有効になっているか、パソコンのマイクが動作しているかを確認してください。ほとんどのパソコンでは、インターネットなしで、音声が本体で直接認識されます。非常に古いプロセッサーの場合のみ、アプリはWindowsの音声入力を使います。その場合は、Windowsのプライバシー設定でオンライン音声認識をオンにし、言語設定にお使いの言語を追加してください。
