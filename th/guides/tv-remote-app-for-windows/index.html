แอปรีโมทสำหรับคอมพิวเตอร์ Windows

Mando TV มีแอปสำหรับ Windows ที่เปลี่ยนพีซีหรือแล็ปท็อปของคุณให้เป็นรีโมททีวีผ่านเครือข่ายในบ้าน พิมพ์บนทีวีด้วยคีย์บอร์ดตัวจริงของคุณ เปิดหน้าต่างรีโมทเล็ก ๆ ไว้ด้านหน้าตอนทำงาน และควบคุมทีวี Samsung, LG, Roku, Google TV หรือ Fire TV ด้วยแอปเดียวกัน

ดูขั้นตอน ดาวน์โหลดฟรี

ดูตอนใช้งานจริง

ทีละขั้นตอน

  1. ติดตั้ง Mando TV ฟรีจาก Microsoft Store บนพีซี Windows 10 หรือ 11
  2. ตรวจสอบว่าพีซีและทีวีอยู่ในเครือข่ายเดียวกัน ผ่าน Wi-Fi หรือสาย LAN ที่ต่อกับเราเตอร์ตัวเดียวกัน
  3. เปิด Mando TV ทีวีจะขึ้นในรายการ คลิกที่ทีวีเครื่องนั้น
  4. ยืนยันหน้าต่างบนทีวี ถ้าทีวีถาม (LG, Samsung) หรือป้อนรหัสที่แสดง (Google TV, Fire TV)
  5. คลิกที่ปุ่มหรือพิมพ์คำค้นหาด้วยคีย์บอร์ด เสร็จแล้ว

ปุ่มลัด (Pro)

ด้วย Pro คีย์บอร์ดพีซีของคุณกลายเป็นรีโมท ปุ่มลูกศรสำหรับเลื่อน Enter สำหรับ OK Backspace หรือ Esc สำหรับย้อนกลับ บวกและลบสำหรับระดับเสียง M สำหรับปิดเสียง และ Spacebar สำหรับหยุดชั่วคราว

รีโมทขนาดเล็ก (Pro)

หน้าต่างรีโมทเล็ก ๆ ที่อยู่เหนือหน้าต่างอื่นทั้งหมด ปรับระดับเสียงหรือหยุดชั่วคราวได้โดยไม่ต้องหยุดงานของคุณ

พิมพ์บนทีวีจากพีซี

คีย์บอร์ดบนหน้าจอของทีวีใช้ช้า ใน Mando TV คุณพิมพ์ด้วยคีย์บอร์ดตัวจริงและข้อความจะไปอยู่ในช่องค้นหาของทีวี ส่วนนี้ใช้ฟรี

รายละเอียดเพิ่มเติม

ดูคู่มือทีละขั้นตอนได้ที่ ควบคุมทีวีจากคอมพิวเตอร์ สำหรับมือถือ อ่าน ใช้มือถือเป็นรีโมทผ่าน Wi-Fi

ฟรีและ Pro

ปุ่มลูกศร OK ย้อนกลับ Home ระดับเสียง ช่อง ปุ่มตัวเลข คีย์บอร์ด การเปิดแอป การเปลี่ยนอินพุต และการเปิดหรือปิดเครื่อง ใช้ฟรี ไม่มีโฆษณา และไม่มีค่าสมาชิก ทัชแพด คำสั่งเสียง แอปโปรด รูทีน และตั้งเวลาปิดเป็นส่วนหนึ่งของ Mando TV Pro ซึ่งซื้อครั้งเดียวและไม่มีค่าสมาชิก บน Windows คุณซื้อ Pro ผ่าน Microsoft Store

สั่งด้วยเสียงจากพีซี (Pro)

ด้วย Pro คุณพูดกับทีวีผ่านไมโครโฟนของพีซีได้ เสียงถูกรู้จำบนพีซีโดยตรง ไม่ต้องใช้อินเทอร์เน็ตและไม่ต้องตั้งค่าอะไรใน Windows สิ่งที่คุณพูดจะไม่ออกจากพีซีและไม่ถูกบันทึกไว้ เฉพาะโปรเซสเซอร์รุ่นเก่ามาก แอปจะกลับไปใช้การป้อนด้วยเสียงของ Windows ซึ่งต้องเปิดการรู้จำเสียงออนไลน์ในการตั้งค่าความเป็นส่วนตัว และเพิ่มภาษาของคุณใน Windows

วิธีทำด้วย Mando TV

Mando TV คือแอปรีโมทอเนกประสงค์สำหรับทีวีของคุณ ดาวน์โหลดฟรี ไม่มีโฆษณา ไม่ต้องสมัครบัญชี ส่วน Pro เป็นตัวเลือกที่ซื้อครั้งเดียว ไม่มีค่าสมาชิกรายเดือน สำหรับ iPhone, iPad, Windows และ Android:

  • ดาวน์โหลดได้ที่App Store
  • ดาวน์โหลดได้ที่Microsoft Store
  • เข้าถึงก่อนใครที่Google Play

Android: เข้าถึงก่อนใครได้ฟรีบน Google Play เข้าร่วมได้ใน 2 ขั้นตอน และช่วยให้เราขึ้นสโตร์ได้เร็วขึ้น

หน้า Microsoft Store: apps.microsoft.com/detail/9N3D7T1DP2SW

รายละเอียดเพิ่มเติมแยกตามแบรนด์:

  • รีโมททีวี Samsung
  • รีโมททีวี LG
  • รีโมท Roku
  • รีโมท Android TV

คำถามที่พบบ่อย

แอปรีโมทสำหรับ Windows ต้องใช้บลูทูธหรือสายหรือไม่

ไม่ต้อง ใช้เครือข่ายในบ้านของคุณ พีซีและทีวีแค่ต้องต่อกับเราเตอร์ตัวเดียวกัน

ควบคุมทีวีรุ่นไหนจาก Windows ได้บ้าง

ทีวี Samsung ระบบ Tizen, ทีวี LG ระบบ webOS, Roku TV และ Player, Google TV และ Android TV รวมถึง Fire TV

ดูภาพจากทีวีบนพีซี หรือฟังเสียงผ่านลำโพงพีซีได้หรือไม่

ไม่ได้ Mando TV เป็นแค่รีโมท ไม่ได้สะท้อนหรือสตรีมภาพจากทีวีมาที่คอมพิวเตอร์

ทำไมเสียงบนพีซี Windows ของฉันถึงใช้ไม่ได้

การควบคุมด้วยเสียงเป็นฟีเจอร์ของ Pro ดังนั้นให้ตรวจสอบว่า Pro เปิดใช้งานอยู่และไมโครโฟนของพีซีทำงาน บนพีซีส่วนใหญ่ การรู้จำเสียงทำงานบนพีซีโดยตรงโดยไม่ต้องใช้อินเทอร์เน็ต เฉพาะโปรเซสเซอร์รุ่นเก่ามากเท่านั้นที่แอปใช้การป้อนด้วยเสียงของ Windows ในกรณีนั้น ให้เปิดการรู้จำเสียงออนไลน์ในการตั้งค่าความเป็นส่วนตัวของ Windows และเพิ่มภาษาของคุณในการตั้งค่าภาษา

  • วิธีเปิดทีวี LG ด้วยมือถือ
  • รีโมททีวีหาย ต้องทำอย่างไร
  • รีโมททีวี LG หาย ใช้มือถือแทนได้อย่างไร

  • ทางเลือกแทนรีโมท Google TV บนมือถือ
  • แอปรีโมทสำหรับ iPhone: แอปเดียวสำหรับทุกทีวี
