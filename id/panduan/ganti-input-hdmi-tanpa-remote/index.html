Cara mengganti input HDMI di TV tanpa remote

Konsol atau streaming player sudah siap, tapi TV tersangkut di input lain dan remote entah ke mana. Untuk mengganti input HDMI tanpa remote ada dua cara: tombol di TV itu sendiri atau HP kamu. Berikut langkah untuk Samsung, LG, dan Roku.

Lihat langkah-langkahnya Unduh gratis

Langkah demi langkah

  1. Coba yang paling mudah dulu: nyalakan konsol atau player. Kalau HDMI-CEC aktif di TV (di Samsung namanya Anynet+, di LG SIMPLINK), TV akan pindah sendiri ke input itu.
  2. Kalau tidak pindah, pakai tombol di TV itu sendiri, di bagian bawah tengah atau di belakang. Di banyak TV Samsung dan LG tombol itu berupa joystick yang membuka menu dengan Sumber atau Input.
  3. Di menu itu pilih inputnya: HDMI 1, HDMI 2, dan seterusnya. Nomornya adalah port tempat kabel tercolok.
  4. Kalau kamu lebih suka memakai HP, hubungkan ke Wi-Fi yang sama, buka Mando TV, lalu ketuk TV kamu.
  5. Di LG dan Roku, ketuk Input lalu pilih port HDMI. Di Samsung, Input mengirim tombol Sumber ke TV, lalu kamu memilih dengan tombol arah dan OK.
  6. Kamu juga bisa menuju input dengan tombol arah dan OK dari layar utama TV. Tergantung merek dan tahun, namanya Sumber, Perangkat terhubung, atau Input. Di Roku TV, itu berupa kotak HDMI di layar utama.

Samsung

Kalau menu tombol di TV tidak punya pilihan Sumber, buka menu layar utama dari HP dan cari Sumber atau Perangkat terhubung di sebelah kiri. Kamu mengontrolnya dengan tombol arah dan OK di Mando TV, yang gratis.

LG

Tekan joystick di TV dan cari Input. Dari HP, kamu juga bisa membuka daftar input di Mando TV dan mengetuk input yang diinginkan.

Roku TV

Di layar utama ada kotak untuk setiap input, misalnya HDMI 1 atau HDMI 2. Bergeraklah dengan tombol arah dan buka dengan OK, gratis.

Kalau TV kamu memakai Android TV atau Google TV

Di Mando TV belum ada daftar input untuk Android TV. Pakai tombol input di TV itu sendiri atau capai input dengan tombol arah dan OK dari layar utama. Kalau kamu tidak punya remote dan ingin menyambungkan HP, baca Android TV tanpa remote.

Bantuan lainnya

Kalau TV sama sekali tidak mau menyala atau kamu tidak tahu harus mulai dari mana, baca Remote TV hilang. Untuk bermain di konsol, panduan Nyalakan TV dan pindah ke HDMI konsol tanpa remote berisi trik HDMI-CEC.

Pertanyaan umum

Apakah mengganti input HDMI gratis?

Ya. Daftar input di Mando TV gratis, begitu juga menyalakan TV serta tombol arah, OK, dan volume. Kamu juga bisa membuka input dari menu TV.

Bagaimana saya tahu input HDMI mana yang harus dipilih?

Lihat port HDMI di TV: masing-masing punya nomor. Pilih yang kabel konsol atau player kamu tercolok.

Bagaimana kalau TV tidak mau menyala?

Nyalakan dengan tombol di badan TV. Kalau kamu pernah menyambungkannya dan mengaktifkan fitur menyalakan lewat jaringan, kamu juga bisa menyalakannya dari HP.
